**Files:**

**Interfaces:**
- Consumes: A1 ve A2 tipleri, S1a şeması.
- Produces: `TurnRequest.economic_action: EconomicAction | None`. Ekonomik alan doluyken `message` yalnız gösterimdir; serbest tur çalışmaz ve iki ayrı mutation oluşmaz. `message` için `min_length=1` (`api/schemas.py:164`) değişmez; panel ve kart istekleri sabit Türkçe gösterim metni gönderir: prepare `"Teklif hazırla"`, confirm `"Teklifi onayla"`, cancel `"Teklifi iptal et"`. `economic_action` istek hash'ine dahildir. Aynı `action_id` farklı gövdeyle gelirse 409 `action_id_conflict` döner.
- Produces: `confirm_offer(state: EconomicState, *, offer_id: str, confirmation_digest: str, operation_id: str, check: Callable[[str, int], str]) -> EconomicResolution`. API `check` olarak `lambda skill, dc: bold_acts._check(session, skill, dc)["result"]` geçirir; bu, mevcut oturum RNG'sini ve snapshot'ını kullanır.
- Produces: `cancel_offer(world: dict, *, offer_id: str) -> bool` ve `cancel_prepared(world: dict, *, actor_id: str, except_offer_id: str | None = None, except_source_action_id: str | None = None, predicate: Callable[[EconomicOffer], bool] | None = None) -> list[str]`. `except_source_action_id` verilirse o action'ın aynı turda hazırladığı teklifler iptal edilmez.
- Produces: `reconcile_offers_after_undo(restored_world: dict, current_offers: dict[str, dict], *, undone_action_id: str) -> None`.
- Produces: `prune_offer_records(world: dict, *, keep: int = 20, protect_action_id: str | None = None) -> None`. `consumed_action_id == protect_action_id` olan kayıt silinmez; API `record.undo_checkpoint["action_id"]` geçirir.
- Produces (`api/serializers.py`): public `GameState`'i kuran `serialize_session_state(session, journal=None, lore_state=None)` (`api/serializers.py:615`) iki alanı yazar. Kayıt yükü olan `game.serialize_game_state()` (`game.py:2182-2198`: format, version, player, world_state, recent_dm_narrations) değişmez; kayıt biçimi ve sürümü aynı kalır.
  - `economic_offer`: oyuncunun tek `prepared` teklifi varsa `public_offer(...)` çıktısı, yoksa `null` (C12).
  - `wallet: {"total_cp": int}`: `currency["player"]` artı kesedeki eski "N Altın|GP" etiketleri, `settle_coin_labels` uygulanmış derin kopyadan bir kez sayılır; canlı dünya normalize edilmez. NPC bakiyeleri yazılmaz.

**Rüşvet akışı (C8, O1):**
- Sonraki normal turda `world_reactions.answer` içinde, `law = ...` satırından önce, açık rüşvet teklifleri iptal edilir: `cancel_prepared(world, actor_id="player", predicate=lambda o: any(e.kind == "bribe_accepted" for e in o.on_accept))`.
- O1 (Kadir): bir tutuklama hold'u başına yalnız İLK rüşvet kartı o turun tırmanmasını durdurur. İşaret `deed["hold"]["bribe_card_opened"]` hold içinde durur (`_press`'in `hold.update` çağrısı onu korur, `world_reactions.py:571`; yeni `_challenge` yeni hold kurar) ve undo görüntüsüyle geri döner.
- `_settle_the_law(session, result) -> tuple[list[str], bool]` olur. İkinci öğe `law_done`'dır: True ise `answer` bu turda `_press`/`_challenge` çağırmaz. Bugünkü `or` zinciri (`world_reactions.py:719`) kaldırılır; boş olmayan demet her zaman doğru sayıldığı için o zincir `_press`'i hiç çağırmazdı. `answer` şunu kurar:

  ```python
  law_lines, law_done = _settle_the_law(session, result)
  law = law_lines if law_done else law_lines + (_press(session, result) or _challenge(session))
  ```

  `_settle_the_law` dalları (amount = okunup sıfırlanan `_bribe_held_out`):

  | Durum | Yapılan | Dönüş |
  |---|---|---|
  | `arrester` yok | hiçbir şey | `([], False)` |
  | amount > 0, hold'da `bribe_card_opened` yok | `lines, prep = bribe(session, amount)`; `prep` varsa ve `prep.status == "prepared"` ise işaret yazılır | prepared: `(lines, True)`; `refused`/`clarification`/`None`: `(lines, False)` |
  | amount > 0, `bribe_card_opened` zaten var | Önce `pressed = _press(session, result) or _challenge(session)`. Savaş başladıysa (`world.combat.active`) `bribe` çağrılmaz, kart hazırlanmaz ve C12 hiçbir kartı iptal etmez. Başlamadıysa `lines, _ = bribe(session, amount)` | savaş: `(pressed, True)`; değilse `(pressed + lines, True)` |
  | amount 0, `_front_deed == "yield"` ve `_gives_in` | `give_up(session)` | `(satırlar, bool(satırlar))` |
  | amount 0, diğer | hiçbir şey | `([], False)` |

  Böylece `_force` turunda hiç rüşvet kartı açılmaz. Kart satırının `law` listesinden sonradan çıkarılmasına ya da aynı turda iptaline gerek kalmaz. `answer` savaş başlayınca `lines`'ı boşaltıp `law`'ı koruduğu için (`world_reactions.py:719-722`), anlatı oyuncunun göremediği bir kartı da duyurmaz.
- Panelden rüşvet kartı açılamaz (A3 `bribe_in_turn_only`); her rüşvet kartı bu akıştan ve `bribe_card_opened` denetiminden geçer.
