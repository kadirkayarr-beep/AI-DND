## Review Focus

1. A debt row closed on a branch name that matches a different, unmerged branch (e.g. `kalan-savas-macera` vs `-2`): each close cites the PR number and sha from `git log origin/main --merges`, not the slug alone.
2. The CLAUDE.md slimming silently drops a safety or quality rule: Task 4 Step 3 greps each kept rule; Task 6 Step 2 lists them for Opus.
3. Merging `origin/main` (Task 0) drops Plan 6's CLAUDE.md/INDEX/register lines: Task 0 Step 3 greps them after the merge and Task 7 Step 1 again before push.
4. A moved file flips LF to CRLF or loses bytes: Task 2 Step 2 `cmp` and `git ls-files --eol`.
5. The phone page leaks code, paths or keys: Task 3 Step 5 limits it to jobs, dates and statuses.
