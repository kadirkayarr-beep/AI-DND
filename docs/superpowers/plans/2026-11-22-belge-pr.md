## Global Constraints

- Every text Kadir reads (roadmap, CLAUDE.md lines, HANDOFF, master-plan header, register status cells) is plain, short Turkish. Never invent a number: a missing token count is written "ölçülmedi"; an unverified fact is written "doğrulanmadı".
- Docs only. No file under `ai-dnd/`, `artifacts/`, `lib/`, `scripts/`, `.github/`, `.claude/` changes. No test is run (none applies); verification is grep/diff.
- Surgical: in `CLAUDE.md`, `INDEX.md`, `debt-register.md` and the master plan only the lines this plan names change.
- Debt rows: every changed or new row has exactly 8 unescaped `|` (`\|` inside a cell is allowed and is not counted). A row is closed only with a merge sha or a grep result on `origin/main` written in the ledger.
- Code questions: `graphify query "<q>"` first, run from `C:/Users/Kadir/Desktop/AI - DND` (read-only).
- Models: implementer Sonnet or Opus; review Opus; never fable. No force push, no branch delete.
- Ledger: `.superpowers/sdd/2026-11-22-belge-pr/progress.md` (git-excluded). Every decision the plan leaves open is a `Ruling: <karar> — <neden> — <yanlışsa maliyeti>` line there.
- Not in this plan: the flaky-test sweep (spec §5 row 2b, §6.4) gets its own plan, written after this PR merges.

## Review Focus

1. A debt row closed on a branch name that matches a different, unmerged branch (e.g. `kalan-savas-macera` vs `-2`): each close cites the PR number and sha from `git log origin/main --merges`, not the slug alone.
2. A rewritten CLAUDE.md line silently drops an existing safety clause (force push ban, CI check, dead-code ask, money/save/Undo review): Task 4 Step 3 greps each clause.
3. Merging `origin/main` (Task 0) drops Plan 6's CLAUDE.md/INDEX/register lines: Task 0 Step 3 greps them after the merge and Task 7 Step 1 again before push.
4. A moved file flips LF to CRLF or loses bytes: Task 2 Step 2 `cmp` and `git ls-files --eol`.
5. The phone page leaks code, paths or keys: Task 3 Step 5 limits it to jobs, dates and statuses.
