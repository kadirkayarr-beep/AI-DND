==================================================
SESSION MANAGER
==================================================

The browser must never directly manipulate GameSession objects.

Create an API-side session manager.

Each web game gets its own session identifier.

Example:

Browser A -> GameSession A
Browser B -> GameSession B

They must remain fully isolated.

Use a cryptographically random opaque session id such as UUID4.

Do not expose Python object ids.

For the first version, an in-memory session registry is acceptable.

Do not introduce Redis/Postgres yet.
