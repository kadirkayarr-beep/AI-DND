============================================================
CAMPAIGN TIME INTEGRATION — IMPORTANT
============================================================

Campaign Time now exists and is authoritative.

This is one of the main reasons #08 was deferred.

Audit all death-related time behavior.

Especially verify the 2024 Stable recovery rule:

A Stable creature at 0 HP that is not healed eventually regains
1 HP after the authoritative rules-defined random duration.

Determine how this should integrate with the existing Campaign Time
scheduler/event system WITHOUT implementing it yet.

The design must preserve:

- Python-owned timing
- authoritative RNG
- save/resume
- receipt replay
- long actions
- travel
- scheduled events
- interruption rules
- combat/noncombat transition

Do not use real-world wall-clock time.

Closing the game must not advance recovery.

Do not let Qwen decide when recovery occurs.

Do not create a second scheduler if Campaign Time already owns timed
world/mechanical progression.

Identify whether the current implementation already handles this
correctly or whether #08 requires a bounded integration.
