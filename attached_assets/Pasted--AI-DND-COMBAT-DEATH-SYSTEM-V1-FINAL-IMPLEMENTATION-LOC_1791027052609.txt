==================================================
8. DEATH SAVING THROW
==================================================

Oyuncu 0 HP ile kendi initiative turuna başladığında server otomatik olarak bir Death Saving Throw çözmelidir.

Oyuncudan ayrıca:

"Death Save at"

gibi bir komut isteme.

Bu otomatik server resolution'dır.

Death Save:

- 1d20
- ability modifier yok
- proficiency yok
- normal skill check değildir
- DC 10
- 10 veya üzeri = success
- 9 veya altı = failure

3 Successes:
→ Stable

3 Failures:
→ Dead

Natural 1:
→ 2 failures

Natural 20:
→ 1 HP
→ Unconscious sona erer
→ death success/failure sayaçları sıfırlanır
→ Prone korunur

Aynı turn için Death Save yalnızca BİR KEZ çözülmelidir.

Aynı request'in retry edilmesi ikinci zar atmamalıdır.

Death Save sonucu Core Resolution V1'in mevcut ortak D20 resolution altyapısını kullanmalıdır.

Yeni bağımsız bir dice engine oluşturma.

==================================================
9. STABLE
==================================================

3 Death Save success sonrasında:

- Stable = true
- Unconscious = true
- HP = 0
- death successes = 0
- death failures = 0
- artık kendi turn'ünde Death Save atılmaz

Stable karakter hâlâ Unconscious'tır.

Stable karakter hasar alırsa:

- Stable kaldırılır
- yeniden Death Save sürecine girer
- ilgili damage-at-0-HP failure uygulanır
- Critical Hit ise iki failure uygulanır
- Massive Damage koşulu varsa instant death uygulanır

Healing alınca:

- HP > 0 olur
- Unconscious sona erer
- Stable sona erer
- death successes/failures sıfırlanır
- Prone korunur

Unconscious sona erdiğinde Prone otomatik temizlenmemelidir.

Mevcut dünya zamanı sistemi 1d4 saatlik Stable iyileşmesini güvenli şekilde destekliyorsa 2024 kuralına uygun olarak uygula.
Yeni bir genel zaman sistemi oluşturma.

==================================================
10. DAMAGE AT 0 HP
==================================================

Oyuncu 0 HP'deyken hasar alırsa:

Normal damage:
→ 1 Death Save failure

Critical Hit:
→ 2 Death Save failures

Damage'in kalan kısmı oyuncunun HP Maximum değerine eşit veya büyükse:
→ instant death

Massive Damage hesabı 2024 kurallarına göre yapılmalıdır.

Bu kontrol Death Save'den bağımsız olarak authoritative Python damage resolution içinde yapılmalıdır.

==================================================
11. DEATH RESOLUTION PHASE
==================================================

En önemli combat davranışı:

Oyuncu Unconscious olduğunda combat sırf oyuncu 0 HP diye bitmeyecek.

Eğer düşmanlar hâlâ yaşıyorsa:

NORMAL COMBAT
→ initiative devam
→ Unconscious player'ın turn'ünde otomatik Death Save

Eğer bütün düşmanlar öldüyse ama oyuncu Unconscious ise:

COMBAT → DEATH RESOLUTION PHASE

geçilebilir.

Bu durumda sistem oyuncunun:

- Stable
- Healing ile tekrar Conscious olması
- Natural 20 ile 1 HP kazanması
- Dead

sonuçlarından birine ulaşmasını çözmelidir.

Oyuncu hâlâ Unconscious iken sistem sessizce:

"combat won"

deyip normal maceraya geçmemelidir.

16. ROLLBACK + IDEMPOTENCY
==================================================

GERİ ALINACAK:

- HP
- combat state

- round
- enemy combat state
- inventory gameplay changes
- location
- campaign gameplay changes
- checkpoint sonrası oluşan journal/campaign state değişiklikleri
