4. CHARACTER DEATH STATE MACHINE
============================================================

The authoritative player-character lifecycle is:

HP > 0
    ↓
normal

HP = 0
    ↓
check Instant Death
    ↓
if not dead:
    Unconscious
    ↓
Death Saving Throws
    ↓
    ├── 3 successes → Stable
    │                  ↓
    │              Unconscious
    │                  ↓
    │              recovery / healing
    │
    ├── 3 failures → Dead
    │
    └── healing / Natural 20
                       ↓
                   HP > 0
                       ↓
                 Unconscious ends
                       ↓
                 Prone remains
                       ↓
                    normal play

Do not create additional unofficial death states unless the existing
architecture already requires an internal representation.

Internal implementation states may exist, but the player-facing
mechanical behavior must match this lifecycle.

============================================================
5. INSTANT DEATH
============================================================

When a character reaches 0 HP:

FIRST:

determine whether Instant Death applies.

Do NOT immediately start Death Saving Throws.

Instant Death includes:

1. Massive Damage.

If damage reduces a character to 0 HP and damage remaining after reaching
0 equals or exceeds the character's HP maximum:

the character dies immediately.

Example:

Max HP = 20
Current HP = 5
Incoming damage = 25

Character reaches 0.

Remaining damage = 20.

20 >= Max HP 20.

Result:

DEAD.

No Death Saving Throw.

2. Other authoritative effects that explicitly kill the character.

Use the existing rules/effect resolver.

Do not let Qwen decide.

============================================================
6. MASSIVE DAMAGE
============================================================

Massive Damage must be evaluated against:

- HP before damage
- incoming damage
- HP maximum.

Do not use:

current HP <= half maximum

for Instant Death.

Do not confuse Bloodied with Massive Damage.

Do not use percentage-based death rules.

============================================================
7. 0 HP WITHOUT INSTANT DEATH

death_save_successes = existing count or 0 according to transition rules
death_save_failures = existing count or 0 according to transition rules

The character is now subject to Death Saving Throws.

Do not allow the player to continue normal actions.

============================================================
10. DEATH SAVING THROW
============================================================

Death Saving Throw is:

1d20

No ability modifier.

No proficiency bonus.

No advantage/disadvantage unless an explicit future authoritative rule
provides it.

Default:

10 or higher = success
9 or lower = failure.

The roll must be generated by Python's existing authoritative RNG.

Do not create a new Death RNG.

============================================================
11. DEATH SAVE TIMING
============================================================

A Death Saving Throw occurs automatically when the Unconscious character
starts their authoritative turn with 0 HP.

The system must resolve it:

ONCE PER TURN.

It must never:

- roll twice for the same turn
- roll on command
- roll because the frontend refreshed
- roll because the browser retried
- roll because narration was rejected
- roll because the combat state was serialized
- roll again during the same turn.

Use the existing Initiative/turn identity.

============================================================
13. NATURAL 1
============================================================

If Death Saving Throw result = 1:

apply TWO failures.

Do not apply one.

Do not perform an additional roll.

Do not roll again.

If this reaches three failures:

character dies.

============================================================
14. NATURAL 20
============================================================

If Death Saving Throw result = 20:

character regains 1 HP.

Result:

HP = 1

Unconscious ends.

Death-save successes/failures reset.

Character becomes capable of normal action again.

The character remains Prone.

Do NOT automatically stand the character up.

Do NOT spend movement.

Do NOT spend an action.

Do NOT invent additional healing.

============================================================
15. THREE SUCCESSES
============================================================

When Death Saving Throw successes reach 3:

character becomes:

STABLE

Stable means:

- HP = 0
- Unconscious remains
- no further Death Saving Throws
- death-save counters reset
- character is not dead.

Do not automatically restore HP.

Do not automatically end Unconscious.

Do not end Stable merely because combat ended.

============================================================
16. THREE FAILURES
============================================================

When Death Saving Throw failures reach 3:

character becomes:

DEAD

Do not allow:

- a fourth Death Save
- automatic stabilization
- automatic healing
- automatic resurrection.

The applicable campaign death mode is then evaluated.

============================================================
17. DAMAGE AT 0 HP
============================================================

If a character has 0 HP and takes damage:

the character suffers a Death Saving Throw failure.

This applies whether the character is:

- Unconscious
- Stable.

If the damage is from a Critical Hit:

apply TWO Death Saving Throw failures.

If the damage equals or exceeds the character's HP maximum:

the character dies immediately.

Do not:

- roll a normal Death Save for the damage
- roll a second damage-related die
- allow Stable to absorb the damage without consequence
- treat the damage as ordinary HP loss.

============================================================
18. DAMAGE TO STABLE
============================================================

When a Stable character takes damage:

1. Stable ends.
2. Character remains at 0 HP unless another authoritative effect changes
   HP.
3. Apply the appropriate Death Saving Throw failure(s).
4. Character returns to the normal Unconscious/death-save lifecycle.
5. If the damage causes Massive Damage / another instant-death rule:
   character dies immediately.

Stable does not protect against damage.

============================================================
19. HEALING AT 0 HP
============================================================

Any genuine healing that restores HP ends:

- Unconscious
- Stable
- Death Saving Throw state.

Reset:

- death-save successes = 0
- death-save failures = 0.

The character becomes conscious when HP becomes greater than 0.

The character remains Prone if the Unconscious transition caused them to
be Prone.

Do NOT automatically stand them up.

Do NOT remove Prone merely because healing occurred.

============================================================
20. TEMPORARY HIT POINTS

Temporary Hit Points are not genuine healing.

If a character has 0 HP:

Do not allow Temporary HP to bypass the Death System.

- world metadata
- event state
