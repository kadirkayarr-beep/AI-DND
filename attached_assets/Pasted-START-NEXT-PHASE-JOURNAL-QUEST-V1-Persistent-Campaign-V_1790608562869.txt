DISCOVERED LOCATIONS
==================================================

When the player canonically reaches/discovers a location, record it.

Each entry may contain:

- location_id if available
- canonical name
- environment
- first_discovered_at
- last_visited_at
- visit_count

Only record locations Python has actually established.

Do NOT record a place merely because the player typed its name.

Example:

Player:
"Waterdeep'e gidiyorum"

If Python does NOT change location:
do not add Waterdeep.

If Python changes canonical location:
record the location.
