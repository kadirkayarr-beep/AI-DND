## Cursor öncelikleri
- **İlk uygulama:** Ana menü için `02 + 01 + 12 + 11`. `04` yalnız alternatif atmosfer örneği.
- **İlk uygulama:** Karakter yaratma için `03 + 07`. `05` karakter özeti için görsel referans.
- **İlerisi:** `06 + 08 + 09 + 10` şimdilik yeni ekran açmak için gerekçe değildir.
- Genel yön: Ouroboros merkezli, karanlık fantastik, sinematik ama sade Forgotten Realms RPG. 1920×1080'de sayfa düzeyinde dikey scroll hedefi yok; 1366×768'de responsive davranış.
- Asıl proje yönü: `ai-dnd/docs/AI_DND_UI_STYLE_DIRECTION_v1_2026-10-10.md`.

## Önemli sınırlar
1. Görseller **referans**, otomatik olarak oyuna dahil edilecek üretim varlıkları değil. Lisans/özgünlük ve varlık kullanım izni değerlendirilmeden kopyalama, dağıtma veya public web sitesine ekleme.
2. `03` içindeki kurgusal büyü/sınıf/istatistikler ve `05` içindeki Mana, Stamina, Evasion gibi örnek sayılar **D&D kuralı değildir**. `06` içindeki görevler ve ödüller kampanya gerçeği değildir.
3. Ouroboros yalnız AI-DND'nin tasarım amblemidir; doğrulanmış Forgotten Realms tanrısı/faksiyonu veya tarihsel sembol diye sunma.
4. Lore otoritesi ortam gerçekliğini, Python oyun gerçekliğini belirler; kampanya olayları kampanya kanonudur. Frontend yalnız sunar.
5. Ana menü ve karakter yaratmayı yenilerken test etmeden scroll veya işlev başarısı iddia etme. Git commit/push, save/Python/Qwen/lore pin değişikliği yok.
