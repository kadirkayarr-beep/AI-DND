==================================================
NARRATIVE DIRECTOR — RICH PROSE CONTRACT CHANGE
==================================================

Goal:

Remove the hard two-short-sentence narration ceiling and replace it with
scene-adaptive narrative length WITHOUT weakening canonical safety.

Do not simply make every response long.

Required behavior:

DIRECT QUERY
Example:
"What is in my inventory?"

→ concise answer

SMALL ACTION
Example:
"I open the door."

→ approximately 1–2 short paragraphs when appropriate

NORMAL STORY ACTION
Example:
"I enter the tavern and approach Kasim."

→ typically 2–5 paragraphs

IMPORTANT SCENE
Examples:
major discovery
emotional NPC conversation
combat aftermath
important reveal

→ may be longer when justified

COMBAT ACTION

→ mechanically concise but narratively vivid;
do not restate every structured combat number in prose

==================================================
NARRATIVE FREEDOM
==================================================

Allow Qwen to create harmless narrative texture:

- sensory detail
- lighting
- sound
- smell
- weather atmosphere
- architecture
- facial expressions
- body language
- pacing
- minor anonymous background activity

But it must NOT create canonical:

- important NPCs
- quests
- inventory
- money
- damage
- healing
- spell effects
- location changes
- quest progress
- XP
- level
- mechanical success/failure

==================================================
PLAYER AGENCY
==================================================

Do not narrate major player choices that were not requested.

Never invent:

- player dialogue
- player beliefs
- player decisions
- attacks
- movement
- item use

unless already established by the player's action or Python result.

==================================================
MEMORY INTEGRATION
==================================================

The richer narrator must consume the Narrative Director context already added:

- canonical current state
- recent turns
- relevant NPC memory
- relevant location continuity
- unresolved threads
- story summary
- scene classification
- anti-repetition context

It must use memory naturally.

Do not dump remembered facts as exposition.

==================================================
ANTI-REPETITION
==================================================

Preserve the new repetition/deduplication protections.

Longer prose must NOT cause:

- repeated tavern introductions
- repeated NPC descriptions
- repeated gestures
- repeated metaphors
- identical combat phrases
- repeated paragraph openings
- constant weather openings

==================================================
SAFETY
==================================================

Do NOT weaken:

- canonical contradiction protection
- narrator safety
- player-action invention protection
- two-call maximum
- rollback behavior
- structured-result authority

Change narrative LENGTH/FREEDOM, not mechanical authority.

PERFORMANCE

Preserve generation headroom.
