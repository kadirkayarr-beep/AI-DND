---
name: Narrative continuity authority
description: Boundary for using narrative continuity without making model prose canonical NPC memory.
---

For narrow deterministic recall of a player's name, prefer the latest explicit player-originated disclosure in canonical NPC memory. If it is absent, use only fitted continuity entries sourced from a player utterance and bound to the same stable NPC ID. Generated narration, summaries, and model claims never establish memory.

**Why:** The narrator can omit a supported name or invent a historical claim. A deterministic response keeps it reliable while preventing generated prose from turning an unsupported claim into a fact.

**How to apply:** Keep continuity request-scoped and post-budget. Resolve the canonical player utterance first, then the selected player-originated entry for the addressed NPC; use this only for exact self-name recall, not general history. Test wrong NPC IDs, model-originated entries, and unrelated historical questions.
